One fortune-cookie message for a software engineer, in a single line of
at most 120 characters. `main.py` (standard library only) writes it
deterministically to `entry.txt` — run it twice and the file is
byte-identical.

## Run

```sh
python3 main.py
```

The entry is written to `entry.txt` (and to `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set, default `/output/entry.txt`).

## Entry

> Your lucky numbers are 200, 404, and the error code you made up at 2 a.m.

73 characters, one line.
